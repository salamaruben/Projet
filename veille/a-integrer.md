# Boîte de dépôt : publications à intégrer au site

Vous avez vu une publication LinkedIn, X ou Facebook d'un candidat qui mérite d'apparaître sur le site ?
Collez-la ci-dessous, dans la zone « À intégrer ». La mise à jour du lendemain matin l'ajoute au site (avec le lien et la mention « déclaration du candidat »), puis vide la zone.

## Comment faire

1. Cliquez sur le crayon (« Edit this file ») en haut à droite de cette page sur GitHub.
2. Collez votre contenu sous « À intégrer ». Une publication par bloc, séparés par une ligne vide.
3. Cliquez sur « Commit changes » (en gardant la branche `claude/site-vercel`).

Pour chaque publication, indiquez si possible :

```
Candidat : Fabiani et Naquet
Lien : https://www.linkedin.com/posts/...
Date : 2026-10-27
Texte : (collez ici le texte de la publication)
```

Le lien et le nom du candidat suffisent. Le texte et la date sont facultatifs mais aident.
Ne mettez jamais de mot de passe ni de code de connexion dans ce fichier.
